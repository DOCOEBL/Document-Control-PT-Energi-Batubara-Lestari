Pindah data ke database baru

Document Control PT Energi Batubara Lestari. Halaman ini menyalin daftar dokumen, temuan audit, dan isi semua file dari database Firebase lama ke database baru. Database lama tidak diubah atau dihapus.

Sebelum mulai: di proyek Firebase baru, aturan dari firebase-rules.json harus sudah di-Publish (Realtime Database, tab Rules), dan akun docoebl@ebl.app harus sudah ada di Authentication. Selama proses berjalan, jangan menutup halaman ini dan jangan mengunggah dokumen baru di website.

1. Database lama (sumber)

Dari Project settings proyek lama di Firebase Console. Kalau apiKey lama tidak bisa didapat, kosongkan kolom ini dan kata sandi lama: daftar dokumen dan temuan tetap disalin, tetapi isi file tidak ikut.

2. Database baru (tujuan)

Salin dari Project settings proyek baru, atau dari config.js repositori baru.
